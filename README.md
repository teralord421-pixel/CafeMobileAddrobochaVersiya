# Пиріжки.lab mobile PWA

Мобильное PWA-приложение для кафе по брендбуку `Пиріжки.lab`: меню, акции, корзина, оформление заказа, выбор города и филиала.

## Запуск

```powershell
python main.py
```

Приложение откроется на `http://127.0.0.1:8000/`.

Для проверки на телефоне в одной Wi-Fi сети:

```powershell
python main.py --host 0.0.0.0
```

После этого откройте в браузере телефона `http://<IP-компьютера>:8000/`.

## Реализовано

- мобильный интерфейс в стиле брендбука: молочный фон, теплый шоколадный цвет, крафтовые карточки, логотип из PDF;
- экраны `Головна`, `Меню`, `Акції`, `Замовлення`, `Міста`;
- поиск по меню, фильтр категорий и быстрый выбор популярных позиций;
- корзина с количеством, удалением позиций, промокодом, скидкой, доставкой и итоговой суммой;
- оформление самовывоза или доставки, выбор филиала, времени и способа оплаты;
- выбор города и филиала с часами работы, адресами и телефонами;
- подтверждение заказа, локальная история и повтор заказа;
- активный заказ со статусом приготовления и QR-кодом для выдачи;
- профиль клиента, автоподстановка имени/телефона, локальная программа лояльности;
- списание бонусов: 100 баллов дают скидку 50 грн в заказе от 100 грн;
- избранные позиции и подробная карточка товара с составом, весом, калориями и аллергенами;
- экспорт и сброс локальных данных приложения;
- PWA manifest, install prompt, offline status и service worker cache.
